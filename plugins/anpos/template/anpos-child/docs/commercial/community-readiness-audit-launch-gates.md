# Community source vs launch gate

The ANPOS Community Repository Readiness / Conformance Audit is implemented in source on this release lane, but it is not an active Marketplace product merely because source certification passes.

A live claim requires real public Marketplace App registration/configuration, production deployment, Setup URL -> PKCE OAuth -> authenticated installation verification -> repository discovery -> bounded audit E2E evidence, current Marketplace compliance verification, and explicit operator activation.

The free acquisition plan therefore remains outside the paid plan array and has no Marketplace plan ID.
