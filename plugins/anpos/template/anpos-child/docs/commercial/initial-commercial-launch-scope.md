# Initial Commercial Launch Scope

Status: **scope decided; external launch gates remain pending**.

ANPOS does not need every future tier to be fully productized before the first legitimate commercial launch.

The initial sequence is:

1. **Community** — genuine free GitHub Marketplace product: Repository Readiness / Conformance Audit.
2. **Developer** — first paid tier only after current GitHub paid eligibility, real Marketplace pricing/plan ID, legal sale approval, verified private release delivery and production E2E are complete.

Pro and Team are explicitly deferred from the initial sale scope until their private premium/billing/support/production evidence is real. Enterprise is contract-only until its policy/control, procurement and supported deployment model is productized.

This decision prevents unfinished higher tiers from blocking Community or Developer launch while preserving fail-closed truth: no tier is activated merely because its source label exists.
