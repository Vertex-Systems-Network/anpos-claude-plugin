# Private Vendor Repository Bootstrap Evidence

Status: **private vendor repositories not yet verified**.

`config/release/private-vendor-bootstrap-evidence.json` defines the evidence needed before either `Vertex-Systems-Network/anpos-commercial-service` or `Vertex-Systems-Network/anpos-commercial-template` can become a vendor source of record.

For each repository, retain proof of private existence, default branch, exact head revision/tree, and deterministic handoff receipt. The repository content must come only from the verified canonical export boundary.

A repository name, a failed/not-found lookup, or a local export does not prove a private vendor repository exists. `vendor_source_of_record_ready` remains false until both repositories and their exact handoffs are verified.
